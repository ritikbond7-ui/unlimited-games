# Unlimited Games 🎮

A hub of **10 free browser games** — no downloads, no sign-up. Just open the site and play.

**▶️ Play live: https://ev-rush-game.pages.dev**

## Games

| Game | File | About |
|---|---|---|
| EV Rush | `ev-rush.html` | Highway EV dodging racer |
| Protest Run 3D | `protest.html` | 3D march runner (Three.js) — INA Market to Jantar Mantar |
| Ludo | `ludo.html` | Classic Ludo with bots |
| Snake | `snake.html` | The timeless snake game |
| Metro Runner | `metro.html` | Endless metro-track runner |
| Sky Flap | `skyflap.html` | Flappy-style flying game |
| Bricks | `bricks.html` | Brick-breaker arcade |
| Memory | `memory.html` | Card-matching memory game |
| Stack | `stack.html` | Tower-stacking timing game |
| Target | `target.html` | Aim and shoot targets |

## How to run locally

Open `index.html` in any browser — everything is plain HTML, CSS and JavaScript in single files, no build step needed.

## Tech

- HTML5 / CSS3 / vanilla JavaScript
- Three.js (inlined) for the Protest Run 3D world
- Hosted on Cloudflare Pages
